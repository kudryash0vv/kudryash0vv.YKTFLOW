## ❄️ О проекте
**YKTFLOW** — это проект, рожденный в самой холодной точке мира. Его задача — обеспечить стабильный и быстрый доступ в сеть, несмотря на любые преграды. Система работает по принципу "нулевого участия": она сама находит источники, сама проверяет их на "живучесть" и сама обновляет витрину для пользователей.

### Основные возможности:
- 🚀 **Turbo-Check**: Многопоточная проверка (500+ потоков) на языке Go.
- 🧊 **Smart Cache**: Фильтрация дубликатов и "зомби-серверов".
- 📱 **Premium UI**: Поддержка метаданных подписки (Profile Title & UserInfo).
- 🌌 **Web Interface**: Современный лендинг с анимацией снега.
- 🔄 **Auto-update**: Полный цикл обновления каждые 4 часа через GitHub Actions.

## 🛠 Техническая архитектура
Система разделена на несколько логических модулей, работающих в едином конвейере.

### 1. Модуль сбора (Scraper)
Скрипт анализирует список источников из `data/sources_mobile.txt`. Поддерживается работа с RAW-ссылками GitHub, Telegram-каналами и другими текстовыми репозиториями.
- **Лимит источников**: 5 (настраиваемый).
- **Парсинг**: Регулярные выражения для протоколов VLESS, VMESS, TROJAN, SS.

### 2. Модуль фильтрации (Checker)
Ядро системы, написанное на Go. Использует конкурентность для одновременной проверки сотен узлов.
- **TCP Dial**: Проверка базовой доступности порта.
- **TLS Handshake**: Проверка валидности сертификатов и Reality-ключей.
- **SetDeadline**: Жесткий лимит 1.5с на каждое соединение для исключения зависаний.

### 3. Модуль упаковки (Encoder)
Формирует финальный файл подписки.
- **Profile-Title**: Устанавливает имя `kudryash0vv.YKTFLOW`.
- **Subscription-UserInfo**: Добавляет визуальный лимит **825 GB** и срок действия до **2026 года**.
- **Base64**: Кодирует весь контент для совместимости со всеми мобильными клиентами.

## 👨‍💻 Для разработчиков

Если вы хотите запустить чекер локально:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Установите зависимости (требуется Go 1.21+):

   ```bash
   go run scripts/checker.go
   ```
